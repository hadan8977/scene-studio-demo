# 以 Figma Make 原项目为前端基础

当前前端直接从用户上传的 `Card Stack.zip` 移植，主要界面文件位于 `components/figma-make/`。它们是实际运行的组件，而非截图或视觉参考。原文件中的布局、Tailwind 样式和 Motion 动画保留；功能连接通过适配层完成。

## 直接沿用的原稿

| 原稿文件 | 当前文件 | 保留内容 |
| --- | --- | --- |
| `src/app/components/HmiFrame.tsx` | `components/figma-make/components/HmiFrame.tsx` | 1920×1080外壳、15px边框、玻璃反光、2.5° / -5°视角、挤出阴影 |
| `PopupSurface.tsx` | 同名组件 | 真实地图背景、底部居中520px弹窗、600px命令栏、spring动画 |
| `ManagerSurface.tsx` | 同名组件 | 288px侧栏、场景磁贴、当前档案、它学会了什么、560px编辑弹层 |
| `SceneCard.tsx` | 同名组件 | 26px标题、连续动作行、细数值条、偏好与不支持说明、卡片底部三个决策按钮 |
| `Composer.tsx` | 同名组件 | 环形微光、生成/追问/错误内容切换 |
| `ReviewPanel.tsx` | 同名组件 | 屏内侧滑评审面板、连接与模型、车况、偏好、时延及裁决 |
| `src/styles/theme.css` | `app/figma-theme.css` | 原稿颜色、字号、圆角和主题变量 |

字体使用相同的 Hanken Grotesk、Noto Sans SC 与 DM Mono，通过 Fontsource 自托管；使用原稿的 Lucide Sparkles 标识。字体与图标许可在 `public/licenses/`。

## 为产品逻辑补上的适配

- 底部切换控件移入屏幕玻璃，所有交互留在车机框内。切换弹窗/应用不再清空草稿。
- `useGeneration.ts` 保持原稿组件接口，连接原有流式生成服务。`bridge.ts` 只转换显示字段；附录 C 输出、114 条注册表与能力裁决仍由服务层决定。
- 模型清单来自项目候选与 OpenRouter 实际目录的交集，接口固定为本站服务端，密钥不进入浏览器。无接口时明确提示，不自动切成回放。
- 禁止、不支持、已调整、规划中和提议中分别保留。无法表达的条件在卡片中展示，不能因遗漏条件而允许保存。
- 自然语言续改沿用当前场景；补充紧凑参数编辑器，可改名、调整取值、增删条件和动作。
- 保存后打开“我的场景”，更新已有条目保持原 ID。已保存内容沿用本浏览器原先的存储格式，并记录档案来源。增加搜索与删除确认。
- 档案“拿走/恢复”接入持久化，并分别保存。温度、灯光、音量、净化均是独立偏好。页面明确标注预置演示档案，未声称已实现自动学习。
- 行驶时严格保留三行摘要，暂停新建、修改与保存。编辑窗口和评审面板支持键盘焦点管理，中文输入法确认不触发提交。

上一版 `app/cockpit-theme.css`、旧的 `scene-studio.tsx` 页面实现、`cockpit-art.tsx` 和 `profile-library.tsx` 均已移除。不会通过旧样式覆盖原稿。

## 验证

42 项服务/能力/存储与显示适配测试；12 条 React DOM 交互旅程，覆盖弹窗、跨视图草稿、保存更新、刷新、删除、应用内创建、追问、英文、手动修改、偏好恢复、行驶状态、连接失败和连续提交。

生产构建与在线接口检查单独完成。DOM 测试不代表浏览器截图或实车视觉验收；真实模型质量与时延仍需要有效 OpenRouter 密钥联调。地图使用真实 OSM 地理数据；车况和档案均为演示数据，不执行车辆动作或自动学习。
