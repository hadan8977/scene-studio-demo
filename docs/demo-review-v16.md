# Figma Make 基础上的产品评审与本轮修改

本轮继续使用上传的 Card Stack 源组件、炭黑/青柠主题、倾斜的 1920×1080 显示器、紧凑弹窗与弹簧动画。评审依据为 PRD v16 的 GEN_001、第一部分，以及后续确认的车机应用与浮层要求。

| 发现的问题 | 本轮处理 |
| --- | --- |
| 抽象曲线缺少真实街区尺度 | 使用上海徐汇滨江 OSM 道路、建筑、公园与水域数据；按现有主题绘制本地 SVG，龙腾大道高亮，标注静态地图和来源，无实时导航伪装 |
| 动作只有图标，没有明确元素分组 | 在同一张卡内按元素分段，空分组隐藏；逐组进入，保持整卡紧凑且操作区固定 |
| 默认继续说话会被当作新建 | 已有提案时默认携带当前场景；提供明确“新建另一个”入口 |
| 续改不够直观 | 提供按当前动作出现的快捷语句、刚改项目反馈和折叠的“为什么这样安排” |
| 应用初次打开过空 | 增加三个时刻入口，以及英文、追问、能力边界和规划能力示例；明确示例来源，不自动保存 |
| 保存磁贴只列能力名称 | 同时显示实际值、完整条件与概念能力标记，触屏上也能看到“打开” |
| 档案页不容易解释偏好影响 | 同一句话的无档案/当前档案对照；逐条拿走偏好时，预览同步更新；明确预置档案和本地存储 |
| 修改动作后偏好标签可能过期 | 标签由当前动作的实际取值重新校验，并使用“与这些偏好一致”的准确表述 |
| 打开存档后车况调整仍显示已保存 | 重新校验预览；变化后标记未保存，浏览器内原存档不自动改写 |
| 运行能力表落后于最新上传目录 | 从 96 条更新为 114 条、版本 `2026-09-07.0807`；只复制运行字段，不公开内部来源、执行映射和演练历史 |
| 新版包含自定义参数的占位值 | 增加时刻、时间段、星期、日期、日期区间和具体名称校验；未绑定参数不能用“自定义”“地点搜索”等字样冒充有效配置 |
| 新增视频/K 歌能力缺少行驶检查 | 停车时标规划中；行驶时禁止打开，允许退出；未落地动作仍最多展示一项 |
| 时延中的理解句出现时间混用了首 token | 单独记录理解句首次非空输出，评审显示服务端计时；重试重新记录理解句时间 |

## 本轮验证

- 42 项服务、能力、结构、存储与显示适配测试。
- 12 条 React DOM 交互旅程：新建、续改、快捷修改、追问、英文、保存刷新、丢弃、删除、车况、偏好、连接异常、连续提交和新增地图/应用入口。
- TypeScript 检查、生产构建、部署后首页/地图/模型接口检查。
- 地图 SVG 已渲染检查。当前环境未提供可用浏览器，因此未完成真实浏览器截图、点击与实车视距验收；DOM 测试不替代这些检查。
- 新增地图、灵感、偏好预览、参数编辑和参数校验文件的定向 lint 通过。全仓库 lint 仍报告现有组件、React Compiler 约束和测试代码诊断，未宣称全仓库 lint 通过。

## 仍然保留的范围与限制

真实 AI 接口待配置有效 OpenRouter 服务端密钥并联调；不能把示例时延当作模型成绩。当前没有自动学习、车辆执行、自动主动门控、三条旅程或完整选型报告。

时间段/重复周期在附录 C 的 `conditions` 字符串契约中表达生效范围，本 demo 不执行调度。带具体参数的自定义音效、声场、收藏地点搜索和应用内指定歌曲尚缺完整参数契约，校验时不允许直接保存占位词。歌曲名称、壁纸和主题可作标注后的概念提案，不代表资源已可用。

地图采用 WGS84 地理数据，静态展示真实街区；高亮表示龙腾大道，不表示规划完成的导航路线，也不读取用户定位。
