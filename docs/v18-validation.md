# v18 产品化修订记录

本轮以 `9763e1b` 为基线，按用户指出的冗余文案、卡片与语音混排、确认按钮、偏好无法编辑、建议页缺少交互五项问题修订。视觉基础保持为上传的 Figma Make Card Stack。

## 界面与操作

- 主动服务从紧凑的“查看方案”进入方案，宽度 580px；保留原有青柠与炭黑、玻璃层次、驾驶员视角与弹簧动画。
- 语音输入、回复、等待和车控反馈放在卡外；车控、普通回应与车控追问不出现场景卡。
- 普通方案展示名称、条件、动作值、相关偏好、必要限制。删除口号、交互演示、重复来源标签、预览教程等文案。普通组合无内部滚动区，详细编辑才使用可滚动表单。
- 确认使用“好”，编辑和创建使用“保存”。修改完成后不会误显示应用按钮。应用过程简短显示状态，可撤销，后续指令会取消尚未完成的旧动作。
- “场景建议”有可用模板、查看、编辑、保存与删除入口。新建支持输入需求或从空白手动配置。
- 偏好支持行内数值修改、添加、编辑、删除、恢复；按档案持久保存，兼容旧停用记录。修改影响后续建议及服务端模型上下文，已有场景不自动改写。
- 保留 114 项注册表、中文与英文生成、流式接口、局部续改保护、能力裁决、相似场景查重及地图投影修复。

- `npm run test:ui`：25 条 React DOM 交互旅程通过（runner 共26项，包含父测试）。覆盖卡外语音、紧凑卡片、应用及撤销、时序取消、查重、手动创建、偏好增删改及刷新。
- `npm run typecheck`、`npm run build`：通过。
