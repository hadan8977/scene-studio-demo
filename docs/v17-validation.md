## 验证结果

- `npm test`：49 项服务与规则测试通过。包括新增案例合法性、分流、门控、复用、合并和地图几何。
- `npm run test:ui`：21 条 React DOM 交互旅程通过（测试运行器连同父测试共报告 22 项）。涵盖旧版存档恢复、局部修改、丢弃、车控追问、偏好、错误、连续提交，以及主动询问、预览、取消旧执行、拒绝冷却、行驶收件箱、重复保存、概念能力不执行和延时取消。
- `npm run typecheck`、`npm run build`：通过。
- 新增的路由、案例、门控、时序、地图与相似度模块及新增组件通过针对性 `oxlint` 检查。全仓 `npm run lint` 仍未通过，问题集中在现有及适配组件的 React Compiler 约束、可访问性规则、测试类型和 Promise 标注；未关闭全局规则，也不宣称全仓 lint 已通过。
- 生产服务接口检查：首页与地图资源 200；具体车控输入 422；没有密钥的场景请求 503；模型目录返回 `configured:false`，本次有 17 个候选模型。
- SVG 地图已单独渲染检查；车辆、道路、地点几何对齐。新视角切换和卡片结构通过 DOM 检查。
- 公开文件集合检查不含原始 DOCX / XLSX、部署目录、备份包或环境密钥；凭据模式扫描无匹配。

## 明确保留的边界

1. 当前没有可用的浏览器自动化环境，没有把 DOM 检查当成真实浏览器截图或实车可读性验收。文字比例、长文换行和分组结构已改；实际显示器上的阅读效果仍需体验确认。
2. OpenRouter 密钥未配置。真实模型质量、实际首句时延和端到端生成仍待联调；受控 SSE 测试不是实际模型验收。
3. 分流与主动规则是本地 demo，车辆、记忆为演示数据，没有实车控制、通用语义分类、自动学习或保存后的条件调度。
4. 打扰额度为当前会话模拟：最多一次主动询问，同类拒绝记录七天截止时间；独立示例按钮会重置情境。本轮不实现跨日 / 跨车额度、完整观测学习、L3/L4 或三条完整用户旅程。
5. 保留两种使用场所：导航上的紧凑服务弹窗，以及应用内的创建、管理、偏好和收件箱。每项动作仍是同张场景卡内的行。
