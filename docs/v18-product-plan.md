# 产品化修订执行计划

基线：`9763e1b`，本地源码 ZIP / Git bundle 与 `backup/v17-9763e1b` 标签保留。依据用户本轮五项反馈执行，优先真实产品的信息层级和操作效率。

1. 恢复 Figma Make 紧凑浮层与弹出动画，宽度 580px，保留可读字号；不用放大容器解决信息过载。
2. 语音输入、回复、等待与车控反馈放在卡外。主动建议先给简短“查看方案”入口；闲聊与直接车控不生成场景卡。
3. 方案卡只显示名称、条件、动作和值、相关偏好与必要限制。常见方案无需滚动；编辑表单按需展开。取消重复理解句、原话、口号、教学说明与来源标签。
4. 主动方案确认用“好”，创建保存用“保存”。应用后提供撤销和保存；保留预览和新指令优先机制，通过过程状态而非大段文字表达。
5. “它的想法”改名“场景建议”，让查看、编辑、保存、删除、新建都有可达入口。删除无意义的长空状态和教程文字。
6. 档案支持手动添加、修改、删除、恢复偏好；温度等用有效范围内的数值编辑。按档案持久化，兼容旧记录，示例和真实生成使用同一份偏好，负面偏好优先。
7. 连接状态与规则集中到设置，界面保留一个全局模式入口，避免将预置内容冒充实时 AI。
8. 验证正常卡片无滚动、卡外语音、分流、确认/撤销、建议管理、偏好增删改与刷新、并发取消、旧存档兼容，完成类型检查、构建和部署。
