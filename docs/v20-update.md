# v20：情境建议与原位保存

本轮按新的产品反馈调整示例入口与保存体验。

## 改动

- 主动服务示例只保留「场景建议」和「直接车控」，移除「普通对话」分类。
- 首页展示等候、心情不好、纪念日和新增英文 `Time to unwind`。原有英文等候情境保留，共 10 个建议案例、其中 2 个英文案例。
- 「心情不好」建议降低灯光与音量；「纪念日」建议柔和灯光、较低音量和浪漫音乐。音乐仍按原子表标注为提议中。所有方案都等待确认。
- 情绪和纪念日输入进入建议流程，不再一概限制为只回应；拒绝、安静模式、驾驶限制和能力校验继续生效。
- 弹窗保存、更新、另存后留在原位，显示保存反馈。用户主动打开场景应用后再管理已保存场景。
- 应用内保存仍关闭编辑窗口并回到应用自己的场景列表。

## 验证

规则测试覆盖情绪、纪念日路由及原子能力；交互回归验证首页中文/英文建议、音乐成熟度、确认前不保存、首次保存与另存不切换窗口、手动进入应用可看到存档。

冻结 p13 和注册表没有修改，真实 API 接入记录仍见 [v19 验证记录](v19-validation.md)。本轮不重复模型评测。

改动前版本保留为 `backup/v19-8219d34`。更早版本文档为历史记录，本文件和 README 描述当前交互。
